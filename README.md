# Responsive Sales & Customer Success Portfolio

A lightweight, data-driven personal portfolio website designed to showcase a unique blend of technical expertise (Computer Science) and high-volume outbound sales and support skills. 

🚀 **Live Demo:** https://britneybn.github.io/britneyportfolio.github.io

## 🛠️ Tech Stack & Architecture

This project was built from scratch without bloated templates or website builders to demonstrate clean, lightweight front-end performance:

*   **Markup:** HTML5 (Semantic and accessible structure)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com) (Utilized via CDN for rapid utility-first responsive styling)
*   **Data Visualization:** [Chart.js](https://chartjs.org) (Leveraged to build interactive, asynchronous data dashboards)
*   **Hosting:** [GitHub Pages](https://github.com) (Deployed using Git version control workflows)

## 📊 Feature Highlights

### 1. Interactive CRM Sales Funnel
Built dynamically using JavaScript and Chart.js. The dashboard flips standard chart architecture horizontally to model a modern B2B SaaS conversion pipeline (from cold outreach to Closed Won). It visualizes key business performance data:
*   A target-driven tracking environment showing structural progression.
*   Hardcoded metric blocks emphasizing a history of **115% quota achievement** and **95%+ QA compliance**.

### 2. Tailored Value Propositions
The layout is optimized for scannability, immediately segmenting my experience into dual functional paths for hiring managers:
*   **Outbound Sales / BDR Core:** Built on past experience pioneering untapped US lead-generation markets and closing telecom accounts.
*   **Customer Support / Success Core:** Built on technical ticket routing, account enrollment setups, and handling CRM platforms.

### 3. Integrated Video Pitch
Includes an asynchronous media block built for embedding video introductions (e.g., Loom), allowing remote recruitment teams to quickly evaluate phone/video presence and client communication style.
